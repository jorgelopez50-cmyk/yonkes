# 🍔 RapiComida - Sistema de Ventas de Comidas Rápidas

Aplicación completa de ventas de comidas rápidas con sistema de pedidos, pagos y panel administrativo.

## 🎨 Características

### Para Clientes:
- ✅ Registro e inicio de sesión
- ✅ Catálogo de productos con búsqueda y filtros
- ✅ Carrito de compras
- ✅ Múltiples métodos de pago colombianos (PSE, Bancolombia, Nequi, Tarjeta)
- ✅ Rastreo de pedidos en tiempo real
- ✅ Historial de pedidos

### Para Administradores:
- ✅ Panel de administración completo
- ✅ Gestión de pedidos
- ✅ Actualización de estados (pendiente, en preparación, en camino, entregado)
- ✅ Control de pagos (pendiente, pagado)
- ✅ Estadísticas de ventas
- ✅ Exportación de datos

## 🚀 Tecnologías

- React 18
- TypeScript
- React Router
- Tailwind CSS v4
- Context API para gestión de estado
- LocalStorage para persistencia
- Sonner para notificaciones

## 📱 Responsive

La aplicación es completamente responsive y funciona en móviles, tablets y desktop.

## ⚡ Rendimiento

- Sin llamadas a API para máxima velocidad
- Gestión de estado optimizada
- Navegación instantánea con React Router
- Persistencia local sin latencia
